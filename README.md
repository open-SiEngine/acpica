# Lib-acpi for Solid

This package contains the acpica libraries together with make files for
building them inside the Solid tree.

# Documentation

This package is an essential part of the Solid Hypervisor and cannot function independently—it relies on other components of the system.
For comprehensive documentation and build instructions, please refer to the official project documentation at https://github.com/open-SiEngine.
